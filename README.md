# StayHealthy

Front-end of StayHealthy, a non-profit healthcare platform (Go Digital initiative)
for patients in remote and underserved areas. Built with React.js, HTML, CSS; UI designed in Figma.

## Setup
1. `git clone https://github.com/<your-username>/stayhealthy.git && cd stayhealthy`
2. `npm install`
3. Create `.env` with `VITE_API_URL=http://localhost:8181`
4. `npm run server` — start the API (port 8181)
5. `npm run dev` — start the dev server
6. `npm run build` — production build in `dist/`

## Features
Sign Up / Login, doctor search, appointment booking and cancelling, reviews, profile card, notifications.
